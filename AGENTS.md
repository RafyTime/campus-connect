## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown under `docs/work/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage state is stored in each issue's `Status:` field. Both ready roles map to `ready`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. Read the root `CONTEXT.md` and relevant decisions under `docs/adr/`. See `docs/agents/domain.md`.
