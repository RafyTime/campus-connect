# Phase 2 acceptance-to-evidence matrix

Status: planned

This matrix traces the Phase 2 specification to tickets 02 through 20. The owning ticket must replace its placeholders before it can move to `completed`. Ticket 16 also records the three stretch decisions. A stretch ticket that does not ship must record `wontfix`, its decision record, and its Phase 3 deferral instead of leaving blank cells.

## How to update the matrix

Use these completion states:

- `planned`: the evidence and its destination are identified, but the feature is not accepted.
- `verified-local`: the named automated tests pass locally and any implementation-time check is recorded.
- `verified-railway`: the production check passes on the deployed commit.
- `captured-final`: final Railway media is captured, dated, linked, and ready for the presentation.
- `wontfix`: a stretch gate is no-go or the complete stretch slice cannot ship. Link the decision and Phase 3 deferral.

Use repository-relative links for committed files. For a course Drive artifact, record a stable Drive folder and filename, not a local machine path. Use `N/A - <reason>` when a type of evidence does not apply. Do not use an empty cell to mean complete.

Every update must preserve these distinctions:

- Automated test and implementation-time evidence may come from local or CI runs.
- A production check must name the deployed commit and check date.
- Ticket 16's core-deployment smoke record and capture rehearsal inform stretch decisions. They are not final submission media.
- Screenshots and the screencast become final evidence only when captured from the final Railway deployment after every stretch path is either accepted or marked `wontfix`.

## Capture and artifact conventions

Record final Railway capture metadata beside the artifact:

```text
Railway URL: <public URL>
Deployed commit: <full Git commit SHA>
Captured: <YYYY-MM-DD, Europe/Budapest>
Captured by: <name>
Source artifact: <course Drive folder and filename>
Repository copy: <repository-relative path, or N/A>
Annotation status: clean | annotated
```

Keep artifacts in these locations:

| Artifact                                                         | Repository                                     | Course Drive folder                                                               |
| ---------------------------------------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------- |
| Evidence plan, matrix, and submission outline                    | `docs/work/phase-2-campus-connect/`            | Optional reference copy                                                           |
| Selected optimized clean screenshots                             | `docs/evidence/phase-2/screenshots/clean/`     | `Phase 2/evidence/source/` holds the full-resolution originals                    |
| Selected optimized annotated screenshots                         | `docs/evidence/phase-2/screenshots/annotated/` | `Phase 2/evidence/annotated/` holds editable and full-resolution annotation files |
| Test, CI, and Railway check records safe for a public repository | `docs/evidence/phase-2/checks/`                | `Phase 2/evidence/checks/` may retain full command or console exports             |
| Narration script or shot list selected for the public repository | `docs/evidence/phase-2/screencast/`            | `Phase 2/submission/screencast/` holds narration source and the H.264 MP4         |
| Final PowerPoint                                                 | Do not commit                                  | `Phase 2/submission/Plata-Leonardo_92111978_DLBCSPJWD01_P2_S.pptx`                |

Capture a clean Railway screenshot first. Copy it before adding callouts, labels, crops, or highlights. Never overwrite the clean source. Remove credentials, session values, personal data, and Railway secrets before any artifact enters the repository. Optimize only the selected repository copies. Keep the full-resolution source, editable annotation file, MP4, and final PPTX in the course Drive folder.
